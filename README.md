# CSV Writer (Gradle Library)

`csv-writer` — Java-библиотека для сериализации объектов в CSV с использованием reflection и аннотаций.

## Возможности
- Сериализация списка объектов одного типа в CSV с заголовком.
- Настройка разделителя через аннотацию `@CsvEntity`.
- Управление порядком и именем колонок через `@CsvColumn`.
- Поддержка `null`-значений, `enum`, коллекций и экранирования специальных символов.
- Автоматическое создание директорий при записи файла.

```bash
  ./gradlew test
```

```bash
  ./gradlew build
```
